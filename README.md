# Etappa

Kostenlose Web-App (PWA) zum Planen von Fernwanderungen – Karte, Routenplanung,
Etappen, Navigation und offline nutzbar. Alle Daten aus freien Quellen, siehe
[DATENQUELLEN.md](DATENQUELLEN.md).

```bash
npm install
npm run dev
```
